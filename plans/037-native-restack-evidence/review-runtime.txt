packages/vite-plugin-react-docgen-typescript/src/docgen/nativeBackend.ts:550
Native union extraction emits `filteredValues` in checker/source order and never consults `config.shouldSortUnions`. Thus a union such as `"z" | "a"` remains in that order in native mode, whereas the established option requires string-sorted values and the legacy backend returns `"a"`, `"z"`. Once the public option is restored, native mode still silently violates it; sort the resolved entries before constructing the value array.
